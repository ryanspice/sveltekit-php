# Command catalogue

Run commands from the repository root. [package.json](package.json) and the linked implementations
define the commands; this catalogue records prerequisites and effects. Use [TESTING.md](TESTING.md)
to select checks and [OPERATIONS.md](OPERATIONS.md) for setup and known gaps.

## Prerequisites

The checkout uses Bun, Node.js >=22.17 and a patched PHP branch accepted by `check:runtime` on PATH. Install locked dependencies with
`bun install --frozen-lockfile`; it downloads packages and runs `prepare`. Browser checks also
need Playwright browser binaries (`bunx playwright install`; CI adds `--with-deps`). npm is
needed for registry/package smoke commands. PowerShell is needed only for the runtime-path helper.

All names in the tables are `bun run <name>` unless a full command is shown. A check can create
temporary files or contact a registry even if it does not change tracked source.

## Development and builds

| Command                                   | Implementation / prerequisites                                           | Outputs and effects                                                                                                                                         |
| ----------------------------------------- | ------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prepare`                                 | `svelte-kit sync` lifecycle hook                                         | Writes generated SvelteKit state; a failed sync fails installation.                                                                                         |
| `dev`                                     | [dev-php.mjs](scripts/dev-php.mjs); PHP + Node + Bun                     | Builds tracked `adapter/index.js` and app output, starts Vite/PHP and source watchers.                                                                      |
| `dev:vite`                                | Vite CLI                                                                 | Frontend dev server only; does not launch PHP.                                                                                                              |
| `build:adapter`                           | `build:adapter:js` followed by `build:adapter:types`                     | Rewrites tracked `adapter/index.js` and recreates `adapter/declarations/`; review both generated diffs.                                                     |
| `build:adapter:js`, `build:adapter:types` | Bun bundler / [build-adapter-types.mjs](scripts/build-adapter-types.mjs) | Individual distribution phases; use the combined command for a complete adapter build.                                                                      |
| `build`, `build:watch`                    | Vite CLI; built adapter                                                  | Generates app output; watch stays running. Adapter cleanup recreates configured output directories.                                                         |
| `preview`                                 | Vite CLI; existing build                                                 | Vite preview only; does not establish PHP host behavior.                                                                                                    |
| `serve:php`                               | PHP CLI; existing `build/`                                               | Serves `127.0.0.1:8080` through root `router.php`; stays running.                                                                                           |
| `build:e2e`                               | [build-e2e.mjs](scripts/build-e2e.mjs)                                   | Rebuilds adapter and six fixture variants; deletes/recreates `build-e2e-*`, writes `.svelte-kit-*`. `--mode=php-static` or `--mode=js-ssr` limits variants. |
| `serve:e2e`                               | [serve-e2e.mjs](scripts/serve-e2e.mjs); matching built fixtures          | Starts PHP and JS sidecar servers; checks build stamps, does not build missing fixtures.                                                                    |
| `build:php`, `build:apache`               | Aliases for `vite build`; built adapter                                  | Run one regular application build. The adapter emits PHP routing and mode-specific Apache rules; no extra helper or second build runs.                      |

## Local checks

| Command                               | Implementation / prerequisites                                                                     | Outputs and effects                                                                                                                       |
| ------------------------------------- | -------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `check`, `check:watch`                | SvelteKit sync + svelte-check                                                                      | Writes generated SvelteKit state; watch stays running.                                                                                    |
| `lint`                                | Prettier check + ESLint                                                                            | Reads the whole repository; reports pre-existing formatting too.                                                                          |
| `format`                              | Prettier write                                                                                     | Rewrites the whole repository; prefer a targeted invocation for a narrow change.                                                          |
| `test:unit`                           | Vitest, `tests/unit/`                                                                              | Unit tests; individual tests may use PHP subprocesses or temporary fixture directories.                                                   |
| `check:runtime`                       | PHP, [check-php-runtime.php](scripts/check-php-runtime.php)                                        | Runs `php -n` to check the CLI security-version baseline; no serving-runtime acceptance.                                                  |
| `test:php`                            | Runtime baseline then PHP, `tests/unit/redeclare_test.php`                                         | Stops on an unsupported/unpatched runtime, otherwise runs the PHP redeclaration regression smoke.                                         |
| `verify:artifacts`                    | [verify-artifact-sync.mjs](scripts/verify-artifact-sync.mjs); Bun                                  | Temporary rebuild compares the tracked bundle. Pass `-- --strict` to fail drift; otherwise advisory outside CI.                           |
| `verify:build`                        | [verify-build-routes.mjs](scripts/verify-build-routes.mjs); existing output                        | Checks generated routes; accepts `--build`, `--mode`, and `--basePath`.                                                                   |
| `verify:output`, `test:verify-output` | [verify-build-output.mjs](scripts/verify-build-output.mjs); existing output                        | Checks mode-specific build shape.                                                                                                         |
| `verify:root-router-parity`           | [verify-root-router-parity.mjs](scripts/verify-root-router-parity.mjs); Bun + PHP + existing build | Starts two PHP servers to compare root/generated router behavior; does not build missing output.                                          |
| `test`, `verify`, `verify:all`        | [verify-all.mjs](scripts/verify-all.mjs); full local toolchain                                     | Builds, checks artifacts, runs unit/PHP, HTTP probes and browser E2E. Starts temporary servers and writes test reports.                   |
| `verify:php-static`, `verify:js-ssr`  | Same driver, selected mode                                                                         | Same effects restricted to the selected mode.                                                                                             |
| `test:sanity`                         | Same driver with `--skipUnit --skipE2E`                                                            | Still builds and performs HTTP/output checks; PHP required.                                                                               |
| `test:e2e`, `pw`, `pw:ui`             | Playwright; matching built fixtures + browser binaries                                             | Runs configured projects and servers; writes `playwright-report/` and `test-results/`. `pw:ui` opens the interactive runner.              |
| `test:e2e:kit3`                       | [playwright.kit3.config.ts](playwright.kit3.config.ts); matching E2E output                        | Kit 3 browser matrix covers both modes, root/subdirectory paths, and desktop/mobile viewports. Separate from the main Playwright command. |
| `verify:remote-functions`             | [verify-remote-functions-policy.mjs](scripts/verify-remote-functions-policy.mjs)                   | Checks source/document policy markers; no hosted request.                                                                                 |
| `verify:release-prep`                 | [verify-alpha-release-prep.mjs](scripts/verify-alpha-release-prep.mjs)                             | Checks metadata, source contracts, tracked env safety, templates and tarball leftovers. No deployment.                                    |
| `verify:alpha`                        | [verify-alpha-readiness.mjs](scripts/verify-alpha-readiness.mjs)                                   | Validates current report/source contracts; does not supply missing hosted evidence.                                                       |

The verification driver accepts `--mode=all`, `--mode=php-static`, `--mode=js-ssr`,
`--basePath=<path>`, `--skipBuild`, `--skipUnit`, and `--skipE2E`. Reuse builds only when their
stamps match the intended inputs. `--skipPhp` reduces coverage; it cannot prove the PHP lane.

No package script publishes to npm. An explicit publish command still requires the applicable
release evidence and authorization; command availability or npm authentication supplies neither.
